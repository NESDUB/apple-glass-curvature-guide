01 / fixed-height vessel

Pills: width changes, height does not.

Change the width to see how the two measured caps stay identical. The incorrect example is intentionally generated using a different rule.

DO · fixed 36pt, measured caps

DON'T ·

Magnified cap overlay

Blue: fitted geometry. Orange: selected incorrect geometry. Equal coordinate scale, not independently stretched.

DO

  • Lock the border-box height at 36pt.
  • Use the same 21.126pt end-cap extent at every width.
  • Center contents vertically; increase width for added controls.
  • Prevent cap compression with a minimum width and overflow policy.

DON'T

  • Let content, padding or zoom text dictate height.
  • Use a semicircle or generic rounded capsule as a substitute.
  • Stretch an already-drawn SVG to different aspect ratios.
  • Adjust curvature by adding shadows or outside strokes.
02 / intrinsic-size vessel

Menus: extend straight edges, not corners.

The same eight-cubic path covers compact and tall menus. Change dimensions while retaining the fitted corner extent.

DO · constant corner extent

DON'T ·

Magnified corner overlay

Compare the actual path segments at the same logical scale.

DO

  • Keep the 18.327pt transition extent fixed.
  • Reflect one symmetric double-cubic corner to all four corners.
  • Allow menu width and height to follow content independently.
  • Preserve zero-curvature joins into straight sides.

DON'T

  • Use percentage-based radii or proportional corner scaling.
  • Replace continuous corners with simple circular arcs.
  • Stretch the complete menu artwork to fit more rows.
  • Trace translucent color bleed or shadow as part of the shape.
